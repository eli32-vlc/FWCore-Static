## Best Proxy Cores Right Now

### 1. Sing-box

Sing-box is a newer core with support for many protocols. However, when using the native apps on macOS and iOS, it is very difficult to configure. It’s better to use Sing-box through clients like **v2rayN** and **Throne**.

Apparently, it does not support **XTLS Reality**, as it is closed source.

---

### 2. Xray

Xray is a fork of the V2Ray core with **XTLS Reality** support added. However, it does not support **Hysteria 2**.
This is a good core to use if you rely on **XTLS Reality Vision**.

---

### 3. Clash

Clash is similar to Sing-box, but older.

---

### 4. V2Ray

Do not use this unless you have no other choice, or you are required to use open source software outside of Xray.
